# Контроль кассовой дисциплины по видео — ForteBank Datathon 26

Сервис принимает видеозапись кассы (.mov, камера сверху) и сообщает, видны ли на ней признаки возможных нарушений кассовой дисциплины. Для каждого найденного случая он выдаёт тип (T1–T13), таймкод, описание того, что видно на кадрах, 1–3 кадра‑доказательства и пункт нормативного акта РК. Детектор людей и локальная мультимодальная модель только описывают видео; решение «нарушение / нет» принимают явные правила (`pipeline/rules.py`), каждое из которых привязано к типу нарушения и пункту нормы (`pipeline/norms.json`). Результат — подсказка для проверки человеком, а не заключение.

## Адреса

- Веб‑интерфейс: https://216-81-248-201.sslip.io/ (ключ не нужен).
- API: https://216-81-248-201.sslip.io/api/v1, ключ в заголовке `X-API-Key`. Ключ команда передаёт жюри отдельно, в репозитории его нет.
  - `POST /api/v1/analyze` — загрузка видео (multipart, поле `file`, .mov или .mp4), ответ `{"job_id": ..., "status": "processing"}`;
  - `GET /api/v1/jobs/{job_id}` — статус и результат: `verdict`, `violations`, `meta`.

```bash
URL=https://216-81-248-201.sslip.io; KEY=<ключ>
curl -s "$URL/api/v1/health"
curl -X POST "$URL/api/v1/analyze" -H "X-API-Key: $KEY" -F "file=@video_017.mov"
# {"job_id":"99c7837d0400","status":"processing"}
curl -H "X-API-Key: $KEY" "$URL/api/v1/jobs/99c7837d0400"
# ... затем {"job_id":"99c7837d0400","status":"done","verdict":"violation","violations":[...],"meta":{...}}
```

Опрашивайте `GET /api/v1/jobs/{job_id}` раз в 2–5 с, пока `status` = `processing`. Полная схема ответа и коды ошибок — в [docs/API.md](docs/API.md).

## Модели

- Qwen3‑VL‑8B‑Instruct (BF16) на локальном сервере vLLM: раскладка сцены, состояния объектов, факты по окнам кадров, проверки вокруг событий.
- YOLO26x (Ultralytics) — детекция людей, плюс собственный трекер: роли, вход и выход, больше двух человек в кабинете.

Всё работает локально на одном GPU‑хосте; облачные AI‑сервисы не используются. Интернет нужен только при установке (пакеты, веса).

## Структура репозитория

| Путь | Содержание |
|---|---|
| `pipeline/` | анализ видео: декодирование (`video.py`), люди (`persons.py`), состояния (`states.py`), факты (`vlm_facts.py`), проверки событий (`checks.py`), правила (`rules.py`), реестр типов и норм (`norms.json`), сборка результата (`analyze.py`); оценка на открытых роликах (`eval.py`, `batch.py`, `offline.py`) |
| `service/` | API и веб‑интерфейс (`app.py`, `static/`), режим‑заглушка (`fake.py`), systemd‑юниты, Caddyfile и скрипты развёртывания (`deploy/`) |
| `tools/` | установка и запуск сервера vLLM (`vllm_install.sh`, `vllm_serve.sh`), имитация нагрузки жюри (`jury_sim.sh`) |
| `analysis/gt_team.json` | разметка команды для 42 открытых роликов (для `pipeline.eval`) |
| `analysis/robust/` | проверка устойчивости к другому ракурсу: генерация ракурсов (`make_aug.py`) и подсчёт (`score.py`) |
| `docs/` | документация |
